# Karan Sawant — Editable Portfolio

A standalone HTML, CSS and JavaScript website. All text, layout, badges, links and animations are real web elements. Portraits and the small robot decoration are image assets. There are no page screenshots or video sections.

## Run
Open index.html in a browser, use VS Code Live Server, or run:

    python -m http.server 8000

Then visit http://localhost:8000.

## Edit the components
Open index.html. Each component begins with a clearly labelled HTML comment:
- HOME COMPONENT: main title, biography and first portrait.
- ABOUT COMPONENT: name and bullet points.
- EDUCATION COMPONENT: school, college, years and descriptions.
- SKILLS COMPONENT: photography and videography text.
- EXPERIENCE COMPONENT: projects, roles and technology badges.
- CONTACT COMPONENT: Gmail, LinkedIn and GitHub destinations.

Change text between HTML tags. Change link destinations in href attributes. Change pictures through the img src attributes. To add a project or education entry, duplicate an article inside its respective component.

## Styling and animation
style.css contains labelled blocks for every component. The :root variables control colours globally. Desktop sections use a 16:9 composition and mobile sections reflow naturally. Longer content may require adjusting that section's spacing or aspect-ratio.

script.js handles the loader, scroll reveals and active navigation. Add class="reveal" to animate an element, data-motion="left", "right" or "rise" to choose its direction, and data-delay="200" for a 200ms delay. Visitors requesting reduced motion see a static page.

The local display font includes the characters used in the supplied design. Newly added characters can fall back to the system font. You can replace the @font-face source with a licensed full font if desired.

No npm, framework or build step is needed. Upload this folder to a static host.
